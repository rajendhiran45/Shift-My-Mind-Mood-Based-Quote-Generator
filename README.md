Shift My Mindset is a simple web application that helps users improve their mood by generating inspirational quotes based on their emotional state.

Users can select a mood such as motivation, happy, sad, or love, and the app instantly provides a relevant quote along with a dynamic background color to match the mood.

Features:
• Mood-based quote generation
• Dynamic background color changes
• Smooth UI animations
• Flask backend API
• Lightweight and responsive design

Tech Stack:
• Python (Flask)
• HTML
• CSS
• JavaScript
